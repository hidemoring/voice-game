# 音声入力ゲーム 試作 v1

仕様は手元の `docs/音声入力ゲーム_プロトタイプ仕様書.md`（v4、非公開）。素のHTML／CSS／JSで、ビルドなし。

矢 → 誕生 → 1歳 … 6歳 → まとめ画面まで。各年齢で、手本の繰り返し（最大5回。5回目のあと3秒押されなければ無音の結果へ）→ 入力（6秒）→ 結果 → 自己申告 → 記録 →「次へ」。6歳は授業の言語（日本・スペイン生まれは英語、アメリカ生まれはスペイン語）で判定する。場面ごとの言葉・人数・結果テキストは `js/data.js` の `SCENES`。

## 動かす

リポジトリ直下で：

```
npm start
```

`http://localhost:8080/prototype/` をPC Chromeで開く。マイクは `localhost` ならHTTPでも使える。スマホで試すにはHTTPS配信（GitHub Pages）が必要。

## 採点のテスト

```
npm test
```

## デバッグ設定（右上の⚙）

- 生まれる国の固定、年齢を選んで始める（1〜6歳）、Plan A（ja-JP固定）／Plan B（その場面で言う言語）の切り替え、テスター名
- 結果画面に認識結果を出す／マイクの代わりにテキストで入力する（判定の確認用）
- 記録の表示・TSVコピー・TSV／JSON保存・消去。記録は端末の localStorage に貯まる

## 公開と反映

`git push` で1〜2分後に https://hidemoring.github.io/voice-game/ へ反映される。ただし GitHub Pages は10分間キャッシュされるので、開いたばかりの端末は古いコードのままのことがある。タイトル画面と⚙の「build」番号（`js/data.js` の `BUILD`。push のたびに上げる）で見分け、古ければ10分待つか、Chrome のサイト設定でデータを消去して開き直す。

## 一時的に閉じる

`js/data.js` の `OPEN` を `false` にして push すると、タイトルが「ただいま準備中」になり、`PASSPHRASE` の合言葉を入れた端末だけ先に進める（⚙も隠れる）。再開は `true` に戻して push。合言葉はソースから読めるので、気軽に遊ばれるのを止める程度の仕組み。Claude に「閉じて」「開けて」と頼めば1回の push で切り替わる。

## 判定の調整

`js/data.js` の場面ごとの `variants`（核になる語の表記ゆれ）と `fillers`（セリフに含まれる核以外の語）を直す。
認識結果は正規化（ひらがな→カタカナ、長音・促音・記号・アクセントを落とす）してから照合する。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面とファミコンRPG風の見た目 |
| `js/data.js` | 国・場面（1〜6歳）の言葉・人数・判定用の語・結果テキスト・点数とファンの決まり |
| `js/judge.js` | 正規化・照合・採点・ファンの内訳（`judge.test.js` でテスト） |
| `js/speech.js` | 音声認識・読み上げ・効果音 |
| `js/transcript.js` | 確定結果のまとめ（Android Chrome の累積型に対応。`transcript.test.js` でテスト） |
| `js/logger.js` | 記録と設定（localStorage）、書き出し |
| `js/sprites.js` | 人物のドット絵（仮。両親・祖母・ネコ・近所の2人・親戚・先生・子ども） |
| `js/app.js` | 画面遷移と進行（場面の繰り返し、結果、まとめ） |
