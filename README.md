# 音声入力ゲーム

音声入力で遊ぶブラウザゲームの企画・試作。世界を旅して人の輪を広げる人生ゲーム。

- 試作：[prototype/](prototype/)（遊び方・動かし方は [prototype/README.md](prototype/README.md)）
- 構想・仕様：非公開（手元の `docs/` にだけ置く）

## ローカルで動かす

```
npm start
```

`http://localhost:8080/` を Chrome で開く（マイクは `localhost` ならHTTPでも使える）。

```
npm test
```

で採点のテストを実行する。
